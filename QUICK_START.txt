⚠️  IMPORTANT - VIDEO PROCESSING ERROR FIX:

If you see "❌ Server Error - HTTP 500" when processing videos:
→ This means FFmpeg is NOT installed (required for video files)

FFmpeg is needed for:
✅ YouTube video downloads
✅ Video file processing (MP4, AVI, MOV, etc.)
✅ Some audio format conversions

Install FFmpeg:
→ Download: https://ffmpeg.org/download.html
→ Or use: choco install ffmpeg (if you have Chocolatey)
→ Or use: scoop install ffmpeg (if you have Scoop)

After installing FFmpeg:
1. Restart your terminal/command prompt
2. Verify: ffmpeg -version
3. Restart the backend server
4. Try processing your video again

What WORKS without FFmpeg:
✅ Microphone recording
✅ MP3 audio files
✅ WAV audio files

What DOESN'T work without FFmpeg:
❌ YouTube downloads → Will show HTTP 500 error
❌ Video files (MP4, AVI, MOV, MKV, WEBM) → Will show HTTP 500 error
❌ Some audio formats (FLAC, M4A) → May show HTTP 500 error

For detailed troubleshooting, see: TROUBLESHOOTING.md
